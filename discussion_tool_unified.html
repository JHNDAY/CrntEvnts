Domination vs. Nondomination

Explore ten contested policy domains using Acemoglu's framework

Acemoglu's Framework

Core Principle

A rule becomes domination when imposed without input from those affected. It supports nondomination when the community has voice in shaping it.

Responsiveness Test

Does the rule reflect the views and priorities of the people bound by it?

Domination Occurs:

✗ Imposed without voice
✗ Communities treated identically
✗ Elite imposes "what is right"
✗ Lost capacity to experiment

Nondomination Requires:

✓ Participate in creation
✓ Responsive to local views
✓ Variation where conditions differ
✓ Capacity to adapt & experiment

The Tension

Shared resources (pandemics, climate, immigration) affect multiple communities. Can genuine self-government exist when issues are interconnected?

Discussion Questions

Ask these for every issue:

  • Who is dominated if nationally mandated?
  • Who is dominated if locally decided?
  • What's the shared resource problem?
  • Can self-government exist given interconnections?
  • What's the capture/elite engineering risk?
