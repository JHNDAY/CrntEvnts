Why no one reads it all

Even a large team can only review the parts that change. Most of the haystack goes unread for years, and some of it is decades old.

Well-tested commercial code still keeps an estimated half a bug to one bug per thousand lines. Most are harmless. The real danger is the few that are security holes.

How the needles get found

Bug hunters rarely look straw by straw. Scanning tools check code for risky patterns, and "fuzzers" feed programs millions of random inputs to see what breaks.

More recently, AI models read code at machine speed. They work like a metal detector swept over the haystack: they still miss things, but they cover ground no person could.

Page, stack and reading figures assume 50 lines a page, 0.1 mm a sheet and 200 lines an hour of careful review. At true scale, the needle would be 1/10,000th the size of one straw.
